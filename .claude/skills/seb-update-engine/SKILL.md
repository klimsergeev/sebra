# Обновление движка

Работает основная сессия, без агентов. Данные пользователя обновление не трогает; ставится только после «да».

## Шаги

1. `python3 engine/scripts/update_engine.py check --json`. Код 3 — нет сети: «Не удалось проверить новую версию: нет связи с сервером. Попробуйте позже». Ответ: `installed` — стоящая версия, `latest` — наибольшая, `newer` — есть ли новее, `changelog` — разделы `CHANGELOG.md` от стоящей (не включая) до новой, `tag_moved: true` — версия на сервере подменена (скажи об этом одной строкой и «Перешлите это сообщение тому, кто посоветовал вам Sebra»).
2. **«Обнови движок»:** `newer: false` — «Новой версии нет: стоит <installed>». Иначе перескажи `changelog` простыми словами, по разделам версий, и спроси «Обновить до <latest>? да / нет».
3. **«Верни движок на версию X.Y.Z»:** X.Y.Z равна стоящей — «Эта версия уже стоит»; больше стоящей — как «обнови движок», но в шаге 4 `update --to X.Y.Z`. Меньше стоящей — прочитай `engine/CHANGELOG.md` и перескажи простыми словами, что уйдёт: разделы от X.Y.Z (не включая) до стоящей; спроси «Вернуть движок на версию X.Y.Z? да / нет».
4. Ответ «да» — `python3 engine/scripts/update_engine.py update --json` (возврат — `update --to X.Y.Z --json`). «Нет» или сообщение о другом — ничего не ставь, вопрос больше не задавай.
5. Итог `update` (JSON: `from`, `to`, `commit`, `pushed`, `lint`; при отказе — только `error`):
   - код 0 и `to` больше `from` — «Движок обновлён до <to>. Начните новую сессию: новая версия загружается при старте сессии»; `to` меньше `from` — «Движок возвращён на версию <to>. Начните новую сессию: новая версия загружается при старте сессии»;
   - код 0 и `to` равно `from` — «Новой версии нет: стоит <from>»;
   - код 1, `error` начинается с «в сессии есть неотправленные сохранения» — выполни команду из этого сообщения (`python3 engine/scripts/commit.py --who seb-update-engine --message "отправка перед обновлением"`) и повтори `update` один раз;
   - код 1, `error` — «эту версию нельзя поставить из облака…» — передай его простыми словами и добавь «Перешлите это сообщение тому, кто посоветовал вам Sebra»;
   - другой отказ — «Обновление не прошло: <error>». База остаётся как до запуска.
