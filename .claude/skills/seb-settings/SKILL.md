# Настройки

Работает основная сессия, без агентов: настройки меняет только `python3 engine/scripts/config.py`, подробный лог собирает только `python3 engine/scripts/trace_log.py export`. Вопросов пользователю нет: неясное — самое вероятное толкование и одной строкой, как понято.

## Какая настройка

| Просьба | Ключ | Значение |
|---------|------|----------|
| Время сводки | `summary.time` | `ЧЧ:ММ` (`8:30` запишется как `08:30`) |
| Время ночного порядка в базе | `gardener.time` | `ЧЧ:ММ` |
| Часовой пояс, город, переезд | `owner.timezone` | зона вида `Europe/Moscow` по городу |
| Автор изменений | `git.author_name` и `git.author_email` — оба сразу | имя и почта (советуй служебную `…@users.noreply.github.com` со страницы https://github.com/settings/emails); «просто Claude» — оба `""` |
| День недельного обзора | `weekly.day` | `monday` … `sunday` |
| Через сколько удалять закрытые задачи | `tasks.delete_after_days` | целое от 1 до 100 000 |
| Через сколько дней без изменений задача — без движения | `tasks.stuck_after_days` | целое от 1 до 100 000 |
| Порог большого документа | `big_docs.text_words`, `pdf_pages`, `scan_pages`, `doc_pages`, `slides`, `table_rows`, `sheet_cells`, `sheets` | целое от 1 до 100 000 |
| Переводить ли цитаты не на русском | `language.translate_quotes` | `yes` — переводить, `no` — не переводить |
| Показывать ли цитаты в ответах | `answers.quotes` | `yes` — показывать, `no` — не показывать |
| Подробный лог для разработчика: включить, выключить | `trace.enabled` | `yes` — писать (так по умолчанию), `no` — не писать |
| Модель агента | `agents.<имя>` | `opus`, `sonnet`, `haiku`, `fable` |
| Уровень обдумывания агента: глубже, быстрее | `<имя>-effort` | `low`, `medium`, `high`, `xhigh`, `max` |

**Модель агента** — только по прямой просьбе пользователя, никогда по своему решению. Ключ — по работе, которую назвал пользователь: приём — `agents.intake`, ответы — `agents.answer`, разбор больших документов — `agents.digester`, порядок в базе — `agents.gardener`, сводки — `agents.reporter`, правила — `agents.rules`, спор — `agents.challenger`, откат и удаление — `agents.restorer`. «Опус», «сонет», «хайку», «фейбл» — то же, что `opus`, `sonnet`, `haiku`, `fable`. Работа неясна или спрашивают, какие модели или уровни обдумывания стоят у агентов, — модели одной командой `python3 engine/scripts/config.py get agents.intake agents.answer agents.digester agents.gardener agents.reporter agents.rules agents.challenger agents.restorer` (строки `agents.<имя>: <модель>`), уровни одной командой `python3 engine/scripts/config.py get intake-effort answer-effort digester-effort gardener-effort reporter-effort rules-effort challenger-effort restorer-effort` (строки `<имя>-effort: <уровень>`), и ответ списком «работа — модель» или «работа — уровень», о том, что спросили, без изменений. Модель самой рутины меняется только в её форме на https://claude.ai/code/routines (выбор модели в поле **Instructions**); ключа в настройках для неё нет.

**Уровень обдумывания агента** — тоже только по прямой просьбе пользователя, никогда по своему решению. Ключ — имя работы из ключа её модели и `-effort`: приём — `intake-effort` (модель — `agents.intake`), спор — `challenger-effort`; «всем агентам» — все восемь ключей одним `set`. Уровни от быстрого к глубокому и слова, которыми их называешь пользователю: `low` — низкий, `medium` — средний, `high` — высокий, `xhigh` — очень высокий, `max` — максимальный. Уровень назван — его значение («максимально глубоко» — `max`, «как можно быстрее» — `low`). «Глубже», «тщательнее», «подольше думай» — на один уровень выше нынешнего, «быстрее», «не думай так долго» — на один ниже; нынешний — из команды уровней в абзаце выше, до `set`. Выше `max` и ниже `low` уровня нет: ничего не меняй и ответь «<работа> уже на самом глубоком уровне обдумывания» или «<работа> уже на самом быстром уровне обдумывания». «Как было», «по умолчанию» — значение того же ключа в `engine/config.default.yaml`.

## Шаги

1. `python3 engine/scripts/config.py set <ключ> <значение> [<ключ> <значение> …] --json`. Код 1 — значение не подошло: скажи пользователю простыми словами, что не так, ничего не сохраняй. Код 2 — ключ написан неверно: сверь с таблицей и повтори.
2. `python3 engine/scripts/commit.py --who seb-settings --message "настройки: <ключи через запятую>" --json <пути из поля files>`. Поле `files` пустое — сохранять нечего (значение уже такое). `status` не `pushed` и не `nothing` — строка о сохранении по разделу «Сохранение» `CLAUDE.md`.
3. Ответ — что стало, одной строкой: «Сводка теперь в 08:30». Модель агента — «<работа> теперь делает модель <значение>, со следующего поручения». Уровень обдумывания — «<работа> теперь на уровне обдумывания „<слово>“, со следующего поручения». Цитаты в ответах — «Цитаты в ответах больше не показываю» или «Цитаты в ответах снова показываю». Подробный лог — «Подробный лог включён. Чтобы прислать его разработчику, напишите „отправь лог“» или «Подробный лог выключен: шаги больше не записываю».
4. Время сводки или ночного порядка: добавь «Поменяйте время и в форме рутины: https://claude.ai/code/routines → рутина <sebra summary | sebra gardener> → поле **Select a trigger**. Время вводите по часам на вашем телефоне или ноутбуке». Часовой пояс: время в форме рутины тоже сверьте с часами на телефоне.

## Прислать лог

Просьба прислать лог («отправь лог», «пришли лог разработчику») — не настройка: таблица и шаги выше не нужны, `config.py` и `commit.py` не запускаются.

1. `python3 engine/scripts/trace_log.py export --json`. Пользователь назвал срок («за месяц», «за два дня») — добавь `--days <число дней>`, иначе без него: будет 7 дней. Код не 0 — ответ «Не получилось собрать лог: <причина простыми словами>», дальше ничего.
2. `events` — 0: ответ «Подробный лог выключен, присылать нечего. Чтобы включить, напишите „включи подробный лог“». Файл не отправляй. Включённый лог записал бы хотя бы этот ход, поэтому пустой лог значит, что он выключен.
3. Иначе — инструмент `SendUserFile`: файл — путь из поля `file`, `display` — `attach`, подпись — «Лог Sebra: шаги и их время, без ваших сообщений и записей». Инструмента нет среди загруженных — загрузи его через `ToolSearch` запросом `select:SendUserFile`. Его нет и там или он вернул ошибку — ответ «Не получилось прислать лог файлом: <причина простыми словами>».
4. Ответ — одна строка: «Лог — в файле. Перешлите его тому, кто посоветовал вам Sebra».
