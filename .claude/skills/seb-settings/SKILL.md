# Настройки

Работает основная сессия, без агентов: настройки меняет только `python3 engine/scripts/config.py`. Вопросов пользователю нет: неясное — самое вероятное толкование и одной строкой, как понял.

## Какая настройка

| Просьба | Ключ | Значение |
|---------|------|----------|
| Время сводки | `summary.time` | `ЧЧ:ММ` (`8:30` запишется как `08:30`) |
| Время ночного порядка в базе | `gardener.time` | `ЧЧ:ММ` |
| Часовой пояс, город, переезд | `owner.timezone` | зона вида `Europe/Moscow` по городу |
| Автор изменений | `git.author_name` и `git.author_email` — оба сразу | имя и почта (советуй служебную `…@users.noreply.github.com` со страницы https://github.com/settings/emails); «просто Claude» — оба `""` |
| День недельного обзора | `weekly.day` | `monday` … `sunday` |
| Через сколько удалять закрытые задачи | `tasks.delete_after_days` | целое от 1 до 100 000 |
| Через сколько задача считается зависшей | `tasks.stuck_after_days` | целое от 1 до 100 000 |
| Порог большого документа | `big_docs.text_words`, `pdf_pages`, `scan_pages`, `doc_pages`, `slides`, `table_rows`, `sheet_cells`, `sheets` | целое от 1 до 100 000 |
| Переводить ли цитаты не на русском | `language.translate_quotes` | `yes` — переводить, `no` — не переводить |
| Модель агента | `agents.<имя>` | `opus`, `sonnet`, `haiku`, `fable` |

**Модель агента** — только по прямой просьбе пользователя, никогда по своему решению. Ключ — по работе, которую назвал пользователь: приём — `agents.intake`, ответы — `agents.answer`, разбор больших документов — `agents.digester`, порядок в базе — `agents.gardener`, сводки — `agents.reporter`, правила — `agents.rules`, спор — `agents.challenger`, откат и удаление — `agents.restorer`. «Опус», «сонет», «хайку», «фейбл» — то же, что `opus`, `sonnet`, `haiku`, `fable`. Работа неясна или спрашивают, какие модели стоят, — `python3 engine/scripts/config.py get agents.<имя>` для всех восьми и ответ списком «работа — модель», без изменений. Модель самой рутины меняется только в её форме на https://claude.ai/code/routines (выбор модели в поле **Instructions**); ключа в настройках для неё нет.

## Шаги

1. `python3 engine/scripts/config.py set <ключ> <значение> [<ключ> <значение> …] --json`. Код 1 — значение не подошло: скажи пользователю простыми словами, что не так, ничего не сохраняй. Код 2 — ключ написан неверно: сверь с таблицей и повтори.
2. `python3 engine/scripts/commit.py --who seb-settings --message "настройки: <ключи через запятую>" --json <пути из поля files>`. Поле `files` пустое — сохранять нечего (значение уже такое). `status` не `pushed` и не `nothing` — строка о сохранении по разделу «Сохранение» `CLAUDE.md`.
3. Ответ — что стало, одной строкой: «Сводка теперь в 08:30». Модель агента — «<работа> теперь делает модель <значение>, со следующего поручения».
4. Время сводки или ночного порядка: добавь «Поменяйте время и в форме рутины: https://claude.ai/code/routines → рутина <sebra summary | sebra gardener> → поле **Select a trigger**. Время вводите по часам на вашем телефоне или ноутбуке». Часовой пояс: время в форме рутины тоже сверьте с часами на телефоне.
