# Sebra — ваш второй мозг

Sebra — личная база знаний, которую ведёт Claude. Вы присылаете ссылки, файлы, фото, мысли и дела — Claude сохраняет всё дословно, раскладывает по темам, людям и проектам, ставит задачи и напоминания, наводит порядок по ночам и каждое утро присылает сводку. Работает в облаке — с ноутбука и с телефона, даже когда ноутбук выключен. Ваши данные лежат в вашей личной закрытой копии на GitHub, видите их только вы.

## Что нужно

- Аккаунт на GitHub (бесплатный подойдёт).
- Подписка Claude с Claude Code и рутинами: Pro, Max, Team или Enterprise.

## Установка

1. Откройте https://github.com/klimsergeev/sebra, нажмите **Use this template** → **Create a new repository**. Придумайте имя (например, `my-sebra`), выберите **Private** и нажмите **Create repository**. Это ваша личная база.
2. Откройте https://github.com/apps/claude, нажмите **Install** (или **Configure**, если уже ставили) и разрешите доступ к своей новой базе (**Only select repositories** → ваша база).
3. Откройте https://claude.ai/code. В строке над полем сообщения нажмите значок облака с названием → **Add cloud environment**. Имя — `sebra`, **Network access** — **Full**. Нажмите **Create environment**.
4. Начните новую сессию на https://claude.ai/code: выберите только свою базу и настройки облака `sebra`.
5. Напишите «привет». Claude проверит, что всё работает, задаст четыре вопроса и поможет создать три рутины — это несколько минут.

## Как пользоваться

- Присылайте что угодно — ссылки, файлы, фото, мысли, дела.
- Спрашивайте что угодно о том, что присылали.
- Поправляйте, если не так, — Claude запомнит.
- Утром придёт сводка.
- «Откати» и «удали» — если нужно; Claude сначала покажет, что изменится.
- Обновления — строкой в недельном обзоре; ставятся по «обнови движок» после вашего «да».
- Если не работает — перешлите сообщение тому, кто посоветовал вам Sebra.
