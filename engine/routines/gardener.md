# Рутина «Садовник»

Каждую ночь наводит порядок в базе: поручает работу агенту `seb-gardener`, а в день недельного обзора — ещё агенту `seb-rules`. Пользователю ничего не отправляет.

## Поля формы

Форма — https://claude.ai/code/routines → **New routine**. Поля — по одному, как их показывает `engine/SETUP.md`.

| Поле формы | Что ввести |
|------------|------------|
| Имя рутины | `sebra gardener` |
| **Instructions** (текст рутины) | Текст из блока ниже, целиком |
| Модель (выбор модели в поле **Instructions**) | самая новая Sonnet в списке (6 октября 2026 — Sonnet 5.5): основная сессия рутины только поручает работу агентам |
| **Select repositories** | `<владелец>/<база>` — репозиторий этой базы, только он |
| Окружение (**Select an environment**) | `sebra` |
| **Select a trigger** | **Schedule**, каждый день (daily), время — `gardener.time` из настроек (обычно 4:07) по часам на вашем телефоне или ноутбуке |
| **Connectors** | Убрать все |

```text
Выполни рутину садовника базы Sebra по файлу engine/routines/gardener.md, раздел «Шаги», по порядку. Сохраняй только командой python3 engine/scripts/commit.py — она отправляет в main. Свою ветку claude/… не отправляй, git push не запускай.
```

Затем **Create** и на странице рутины — **Run now**.

## Шаги

Пользователя в рутине нет: вопросов не задавай. Ты — основная сессия рутины: сама данные не пишешь, только поручаешь агентам и вызываешь команды из шагов. Поручение — инструментом Agent, `subagent_type` — имя агента, без параметра `model`, текст строго по шаблону (ЗАДАЧА — из шага, СЕЙЧАС — вывод шага 1, остальное — «нет»):

```text
ЗАДАЧА: <строка из шага>
СЕЙЧАС: <вывод python3 engine/scripts/collect.py now>
МАТЕРИАЛ: нет
ВЛОЖЕНИЯ: нет
СЛОВА ПОЛЬЗОВАТЕЛЯ: нет
РЕШЕНИЯ: нет
ВЕРНИ: блок «Отчёт агента».
```

Сбой шага (команда вернула не 0, агент вернул ИТОГ «не сделано» или «нужно решение», отчёта нет) не останавливает рутину: запиши причину `python3 engine/scripts/journal.py add --who gardener --action "сбой" --target engine/routines/gardener.md --note "<шаг>: <причина или вопрос агента>"` и переходи к следующему шагу.

1. `mkdir -p /tmp/sebra`; `python3 engine/scripts/collect.py now` (СЕЙЧАС; последнее слово — день недели); `python3 engine/scripts/config.py get weekly.day`.
2. Поручи `seb-gardener`, ЗАДАЧА «Садовник: навести порядок».
3. Если день недели из шага 1 равен `weekly.day` — поручи `seb-rules`, ЗАДАЧА «Слить похожие правила».
4. Свои правки агенты уже сохранили. Затем — `python3 engine/scripts/journal.py add --who gardener --action "проход" --target data --note "<ИТОГ и ДЛЯ ПОЛЬЗОВАТЕЛЯ садовника одной строкой>"` и `python3 engine/scripts/commit.py --who gardener --message "проход"` (без путей: уходит журнал). Так у каждого запуска есть коммит `gardener: проход` — и при пустой базе.
