# Рутина «Сводка»

Каждое утро собирает сводку дня (агент `seb-reporter`), в день недельного обзора — ещё недельный обзор, и присылает одно push-уведомление.

## Поля формы

Форма — https://claude.ai/code/routines → **New routine**. Поля — по одному, как их показывает `engine/SETUP.md`.

| Поле формы | Что ввести |
|------------|------------|
| Имя рутины | `sebra summary` |
| **Instructions** (текст рутины) | Текст из блока ниже, целиком |
| Модель (выбор модели в поле **Instructions**) | самая новая Sonnet в списке (6 октября 2026 — Sonnet 5.5) |
| **Select repositories** | `<владелец>/<база>` — репозиторий этой базы, только он |
| Окружение (**Select an environment**) | `sebra` |
| **Select a trigger** | **Schedule**, каждый день (daily), время — `summary.time` из настроек (обычно 9:07) по часам на вашем телефоне или ноутбуке |
| **Connectors** | Убрать все |

```text
Выполни рутину сводки базы Sebra по файлу engine/routines/summary.md, раздел «Шаги», по порядку. Шаг отправки уведомления выполни всегда, даже если предыдущие упали: пришли одно push-уведомление по шаблону из раздела «Уведомление» того же файла. Сохраняй только командой python3 engine/scripts/commit.py — она отправляет в main. Свою ветку claude/… не отправляй, git push не запускай.
```

Затем **Create** и на странице рутины — **Run now**. При ручном запуске уведомление не приходит — только при запуске по расписанию.

## Шаги

Пользователя в рутине нет: вопросов не задавай. Ты — основная сессия рутины: сама данные не пишешь, только поручаешь агентам и вызываешь команды из шагов. Поручение — инструментом Agent, `subagent_type` — имя агента, без параметра `model`, текст строго по шаблону (ЗАДАЧА — из шага, СЕЙЧАС — вывод шага 1, остальное — «нет»):

```text
ЗАДАЧА: <строка из шага>
СЕЙЧАС: <вывод python3 engine/scripts/collect.py now>
МАТЕРИАЛ: нет
ВЛОЖЕНИЯ: нет
СЛОВА ПОЛЬЗОВАТЕЛЯ: нет
РЕШЕНИЯ: нет
ВЕРНИ: блок «Отчёт агента».
```

Сбой шага (команда вернула не 0, агент вернул ИТОГ «не сделано» или «нужно решение», отчёта нет) не останавливает рутину: запиши причину `python3 engine/scripts/journal.py add --who summary --action "сбой" --target engine/routines/summary.md --note "<шаг>: <причина или вопрос агента>"` и переходи к следующему шагу. Сводку за сегодня, если она уже есть, агент не перезаписывает, а дописывает разделом «Обновление <ЧЧ:ММ>».

1. `mkdir -p /tmp/sebra`; `python3 engine/scripts/collect.py now` (СЕЙЧАС; последнее слово — день недели); `python3 engine/scripts/config.py get weekly.day`.
2. Поручи `seb-reporter`, ЗАДАЧА «Ежедневная сводка и строка уведомления».
3. Если день недели из шага 1 равен `weekly.day` — поручи `seb-reporter`, ЗАДАЧА «Недельный обзор».
4. Отправка уведомления: пришли одно push-уведомление. Текст — ДЛЯ ПОЛЬЗОВАТЕЛЯ из отчёта шага 2, ровно одна строка; отчёта нет — строка «Sebra <ДД.ММ>: сводка не собрана, сбой: <шаг>».
5. Уведомление отправлено — `python3 engine/scripts/remind.py done --through <сегодня> --json`, затем `python3 engine/scripts/commit.py --who summary --message "напоминания отправлены" <пути из поля deleted>` (строки журнала уходят тем же коммитом; `deleted` пуст — коммит без путей, только журнал). Не отправлено — напоминания остаются и попадут в следующую сводку с пометкой «за прошлый день»; строки журнала сохрани `python3 engine/scripts/commit.py --who summary --message "уведомление не отправлено"`.

## Уведомление

Одна строка: «Sebra <ДД.ММ>: напоминаний <N>, на сегодня <N>, просрочено <M>, зависших <K>; садовник: <C> изменений». Добавки через запятую, только если есть: «разбирается документов <D>», «вышел движок <X.Y.Z>», «сбой: <шаг>». Пустой день — «Sebra <ДД.ММ>: дел нет, ничего не менялось, зависших задач нет». Первые 100 знаков — главное: телефон показывает начало строки.
