# Настройка базы Sebra

Этот файл — для Claude. По нему основная сессия настраивает новую базу, когда хук начала сессии пишет «База не настроена» или в корне нет `config.yaml`.

## Как вести человека

- По шагам ниже, по порядку. В одном сообщении — один вопрос или одно действие.
- Кнопки и поля сайтов — по-английски, как на экране, жирным: **New routine**, **Run now**.
- Не говори слов «коммит», «репозиторий», «ветка», «окружение», «токен». Вместо них — «база», «сохранить», «настройки облака».
- Вопросы шага 2 — единственные вопросы настройки. Ответа нет или «не знаю» — значение по умолчанию, без переспрашивания.
- При любой остановке — что не так, простыми словами, и строка «Перешлите это сообщение тому, кто посоветовал вам Sebra».
- Человек прислал материал до настройки — он уже услышал «Сначала настроим базу…»; выполни его сообщение после шага 8.

## Шаги

1. **Проверка (Claude).** Выполни по очереди; первая неудача — остановка:
   - `git rev-parse --show-toplevel` — текущая папка. Иначе: «Эта сессия открыта не только с вашей базой. Начните новую сессию и выберите в ней только вашу базу».
   - `python3 --version` — 3.11 или новее. Иначе: «В облаке слишком старый Python».
   - `git ls-remote https://github.com/klimsergeev/sebra` — код 0. Иначе: «Нет связи с сервером Sebra».
   - `python3 engine/scripts/collect.py now` — код 0.
   - `python3 engine/scripts/fetch_page.py https://example.com` — код 0. Иначе: «У этой сессии нет полного доступа в интернет. На https://claude.ai/code в строке над полем сообщения нажмите значок облака — на нём название настроек этой сессии, **Claude Env** или **Default**. В открывшемся списке, в разделе **Cloud**, наведите на эти настройки и нажмите значок шестерёнки справа — откроется окно **Edit environment**. В поле **Network access** выберите **Full** и нажмите **Save changes**. Новые настройки облака не создавайте. Через минуту напишите „готово“ — я проверю ещё раз». На „готово“ — повтори шаг 1 с начала. Снова нет доступа — «Начните новую сессию на https://claude.ai/code: выберите только вашу базу и те же настройки облака, в которых включили **Full**, и напишите „привет“».
2. **Вопросы (Claude)** — по одному, дословно:
   1. «В каком городе вы живёте? Это нужно, чтобы сводка приходила по вашему времени». Город переведи в зону вида `Europe/Moscow`. По умолчанию — `UTC`.
   2. «Как подписывать изменения в базе: просто „Claude“ или вашим именем?». «Claude» или нет ответа — оба поля автора пустые. Именем — следом: «Какую почту указать? Советую служебную почту GitHub вида …@users.noreply.github.com — она есть на странице https://github.com/settings/emails и не показывает ваш настоящий адрес».
   3. «Во сколько присылать сводку? Обычно — 9:07». По умолчанию — `09:07`.
   4. «Во сколько наводить порядок в базе? Обычно — 4:07, пока вы спите». По умолчанию — `04:07`.
3. **Настройки (Claude):** `python3 engine/scripts/config.py init --set owner.timezone=<зона> --set git.author_name=<имя> --set git.author_email=<почта> --set summary.time=<ЧЧ:ММ> --set gardener.time=<ЧЧ:ММ>` (подпись «Claude» — без двух `--set git.…`; значения с пробелами — в кавычках: `--set "git.author_name=Анна Петрова"`). Код 1 «config.yaml уже есть» (настройку прервали и начали снова в той же сессии) — те же значения через `python3 engine/scripts/config.py set <ключ> <значение> …`. Другой код 1 — значение не подошло: скажи, какое, и задай его вопрос ещё раз.
4. **Версия движка и правила (Claude):** `python3 engine/scripts/update_engine.py init` — пишет `engine.lock` и создаёт `rules.local.md`. Отказ — остановка.
5. **Сохранение (Claude):** `python3 engine/scripts/commit.py --who setup --message "база настроена" config.yaml rules.local.md engine.lock`. Код 3 с `GH007` (GitHub не принимает изменения, подписанные почтой, которую вы скрыли): попроси человека открыть https://github.com/settings/emails и снять галочку **Block command line pushes that expose my email**, затем выполни ту же команду ещё раз (уже сделанное сохранение отправится). Другой отказ — остановка.
6. **Три рутины (Человек).** По очереди: «Садовник» (`engine/routines/gardener.md`), «Сводка» (`engine/routines/summary.md`), «Разбор» (`engine/routines/digester.md`). Для каждой:
   - покажи поля из раздела «Поля формы» её файла, по одному полю в сообщении, с подставленными значениями: база — `<владелец>/<имя>` из `git remote get-url origin` (две последние части адреса, без `.git`); время — `python3 engine/scripts/config.py get gardener.time` или `summary.time`; текст для поля **Instructions** — блоком, чтобы его можно было скопировать целиком;
   - перед полем времени: «Время вводите по часам на вашем телефоне или ноутбуке сейчас»;
   - начни с «Откройте https://claude.ai/code/routines и нажмите **New routine**», закончи «Нажмите **Create**, затем на странице рутины — **Run now**, и напишите „готово“».
7. **Проверка рутины (Claude)** — после каждого «готово»: `git fetch origin main`, затем `git log FETCH_HEAD -10 --format=%s` (не `origin/main`: в облачной копии эта ссылка может не обновляться обычным `fetch`). Ищи строку этой рутины: у «Садовника» — `gardener: проход`; у «Сводки» — строку, которая начинается с `seb-reporter:` (при **Run now** уведомление не приходит, и строки `summary:` может не быть); у «Разбора» — `digester: нечего разбирать`. Нет — «Рутина ещё работает. Напишите „готово“ ещё раз через пару минут»; после третьей неудачной проверки — назови поля, которые сверить: база, **Select an environment** (те же настройки облака, что у сессий базы, — **Claude Env** или **Default**, с **Network access** — **Full**), текст **Instructions**, пустые **Connectors**.
8. **Готово.** «База настроена». Затем — строки раздела «Как пользоваться» из `README.md` в корне базы, дословно. Если человек присылал материал до настройки — выполни его сообщение.
